# lms-cli v0.4.3

## 新增

- 新增 **Claude Code 插件**和仓库插件市场。在 Claude Code 中运行 `claude plugin marketplace add zs-andy/lms-cli`，再运行 `claude plugin install lms-cli@lms-cli`。插件注册只读的 `lms mcp` 服务和 Claude Code 版 `lms-query` 技能，位于 `plugins/lms-cli-claude/`。
- 插件不会安装 CLI，需要 `lms` 已在 PATH 中；先运行 `lms setup --no-codex` 配置学校。也可以直接运行 `claude mcp add --scope user lms -- lms mcp`，两种方式不要同时启用。
- 只读的 `lms` 工具带有 MCP 只读标注，可在 Claude Code 权限设置中按需放行；会修改本地配置或打开登录窗口的工具（`lms_profile_add`、`lms_profile_use`、`lms_auth_login`、`lms_items_upsert`）建议保持逐次确认。

## 说明

- CLI、MCP 工具、授权流程和学校连接行为与 0.4.2 相同，本版本没有运行时代码变化，仅版本号随发布同步。
- Codex 插件的内容和行为不变，只同步了 manifest 中的版本号。Claude Code 插件与 Codex 插件互相独立。
- Claude Code 插件通过 Git 市场分发，不包含在 npm 包中。

## 安装与更新

推荐使用自包含 CLI 安装包；已经安装的用户可运行 `lms update`，确认后更新。程序更新保留学校配置、凭据和本地待办。独立授权 App 是可选附件，不是 CLI 使用的前置步骤。

请下载与操作系统和 CPU 架构匹配的附件，并使用同一 Release 的 `SHA256SUMS.txt` 核对文件完整性。学校额外要求的 CAPTCHA、推送 MFA 和设备合规检查仍需用户完成；本版本不绕过学校验证或保证永久免登录。

## 验证范围

发布前检查包括类型检查、100 项自动化测试（含 3 项 Claude Code 插件一致性测试）、依赖审计，以及在隔离配置目录中从插件市场安装并确认 MCP 服务可连接。真实学校兼容范围以 `docs/VALIDATION.md` 为准；Claude Code 插件尚未针对真实学校账号做完整验收。
