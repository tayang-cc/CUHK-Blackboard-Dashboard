# lms-cli v0.4.4

## 修复与改进

- **更新检查不再占用 GitHub 匿名 API 额度。** 匿名 REST API 每小时每个 IP 只有 60 次，校园网、VPN 等共享出口很容易用完，此前会显示“暂时无法检查更新”。现在优先读取 github.com 的公开 Release 页面：已是最新版时只需 1 个请求；发现新版时再并行确认本系统的安装包和校验和已经发布。仅当这些页面无法访问时才退回原来的 API。
- 只接受 GitHub 自己的域名，重定向不会被自动跟随；发现新版后，仍由 `lms update` 在你确认后下载，并校验 SHA-256、归档安全以及新版本能否运行。更新检查与下载器共用同一份受信任域名清单。
- MCP 会话中的更新提醒沿用 0.4.3 的重试：检查失败后 60 秒，下一次查询会再试一次。更新仍需用户确认，不会静默安装；`LMS_UPDATE_CHECK=0` 仍可关闭自动检查。

## 说明

- 学校连接、授权流程和 MCP 工具与 0.4.3 相同；Codex 插件与 Claude Code 插件只同步了版本号。
- 已知限制：安装脚本（`install.sh`、`install.ps1`）在不指定版本时仍通过匿名 API 解析最新版本，本版本没有改动。共享出口 IP 上首次安装如果遇到限流，可使用 `--version vX.Y.Z`（PowerShell 为 `-Version`）指定版本。

## 安装与更新

推荐使用自包含 CLI 安装包；已经安装的用户可运行 `lms update`，确认后更新。程序更新保留学校配置、凭据和本地待办。独立授权 App 是可选附件，不是 CLI 使用的前置步骤。

请下载与操作系统和 CPU 架构匹配的附件，并使用同一 Release 的 `SHA256SUMS.txt` 核对文件完整性。学校额外要求的 CAPTCHA、推送 MFA 和设备合规检查仍需用户完成；本版本不绕过学校验证或保证永久免登录。

## 验证范围

发布前检查包括类型检查、111 项自动化测试（含 7 项更新来源测试：只走 github.com 页面、一次请求的最新状态判断、API 兜底、恶意或异常重定向拒绝、安装包缺失提示、无稳定版）、依赖审计，并在匿名 API 额度已耗尽（HTTP 403）的真实网络下验证新检查仍能发现新版本。真实学校兼容范围以 `docs/VALIDATION.md` 为准。
