# lms-cli v0.4.6

## 修复

- **慢网络下 `lms update` 不再因为固定超时而永远下载失败。** 此前整个下载只允许 180 秒；在约 0.5 MB/s 的网络上，176 MB 的安装包需要约 6 分钟，永远超时，并且错误被笼统地显示成 `INTERNAL`，看不出原因。现在只有连续 60 秒收不到任何数据、或总时长超过 30 分钟时才会中止；只要数据持续到达就会一直下载。
- **下载失败时给出明确的提示。** 数据中断、总时长超限、网络中断或连接被重置、安装包超过大小上限，都会说明“当前版本保持不变”，并提示可以从发布页面手动下载安装包、核对 `SHA256SUMS.txt` 后用 `install.sh --archive` 离线安装，不再显示 `INTERNAL`。

## 说明

- 下载地址与重定向白名单、SHA-256 校验、归档安全检查、激活前的运行检查都没有改变；更新仍需用户确认，不会静默安装。
- 已知限制：下载仍不支持断点续传，连接中途中断后需要重新开始；`install.ps1` 未改动，不指定版本时仍使用 REST API 解析最新版本，被限流时请用 `-Version` 指定。
- 学校连接、授权流程和 MCP 工具与 0.4.5 相同；Codex 插件与 Claude Code 插件只同步了版本号。

## 安装与更新

推荐使用自包含 CLI 安装包；已经安装的用户可运行 `lms update`，确认后更新。程序更新保留学校配置、凭据和本地待办。独立授权 App 是可选附件，不是 CLI 使用的前置步骤。

请下载与操作系统和 CPU 架构匹配的附件，并使用同一 Release 的 `SHA256SUMS.txt` 核对文件完整性。学校额外要求的 CAPTCHA、推送 MFA 和设备合规检查仍需用户完成；本版本不绕过学校验证或保证永久免登录。

注意：旧版本（0.4.5 及更早）自带的更新器仍有 180 秒的固定超时，在很慢的网络上可能无法通过 `lms update` 升级到本版本；此时请按上面的方式手动下载并离线安装一次，之后的更新将使用新的下载限制。

## 验证范围

发布前检查包括类型检查、125 项自动化测试（含 7 项下载限制测试：持续到达的慢速下载不因总时长失败、数据中断、持续缓慢到达被总时长上限终止、等待响应头时中断、网络错误与超大文件、重定向策略不变、生产限制值）、依赖审计。新下载函数已在真实网络上完整下载并校验一个 176 MB 的发布包；“比旧的 180 秒限制更慢”的场景由模拟数据流的测试覆盖。真实学校兼容范围以 `docs/VALIDATION.md` 为准。
