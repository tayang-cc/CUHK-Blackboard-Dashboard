# lms-cli v0.4.7

## 修复与改进

- **更新下载支持断点续传。** `lms update` 的下载遇到连接重置、停滞、服务器暂时报错（5xx）或响应提前结束时，会用 `Range` 请求从磁盘上已有的字节继续，最多尝试 5 次，不再整包重新下载；服务器忽略或拒绝 `Range`（或返回的 `Content-Range` 对不上）时，自动丢弃已下载的部分并从头开始。30 分钟的总时长上限由所有尝试共享；连续 60 秒收不到数据才算停滞。SHA-256 校验、归档安全检查和激活前的运行检查都没有改变，续传前会对已有数据重新计算哈希，最终仍校验整个文件。
- **`install.sh` 的下载不再被固定 180 秒掐断。** 此前安装脚本用 `curl --max-time 180` 下载安装包，在慢网络上永远下不完。现在只有速度连续 60 秒低于 1 KB/s 才放弃，单次最长 30 分钟，失败自动重试最多 5 次，并用 `-C -` 从已下载的位置继续；只使用长期存在的 curl 选项，旧版 curl 也能运行。
- **`install.ps1` 不再依赖匿名 API 解析最新版本。** 未指定版本时，脚本读取 github.com 最新版本页面的重定向（只接受本仓库的稳定版本标签），解析不出来才退回 REST API。在 Windows PowerShell 5.1 和 PowerShell 7 中行为一致。

## 说明

- 已知限制：`install.ps1` 的下载本身没有断点续传。
- 0.4.6 及更早版本的 `lms update` 没有断点续传；在非常不稳定的网络上，首次升级到本版本时也可以直接运行一键安装命令（`install.sh` 现在会续传并重试），之后的更新将使用新的下载逻辑。
- 学校连接、授权流程和 MCP 工具与 0.4.6 相同；Codex 插件与 Claude Code 插件只同步了版本号。

## 安装与更新

推荐使用自包含 CLI 安装包；已经安装的用户可运行 `lms update`，确认后更新。程序更新保留学校配置、凭据和本地待办。独立授权 App 是可选附件，不是 CLI 使用的前置步骤。

请下载与操作系统和 CPU 架构匹配的附件，并使用同一 Release 的 `SHA256SUMS.txt` 核对文件完整性。学校额外要求的 CAPTCHA、推送 MFA 和设备合规检查仍需用户完成；本版本不绕过学校验证或保证永久免登录。

## 验证范围

发布前检查包括类型检查、142 项自动化测试（含 10 项续传测试、4 项 `install.sh` 下载函数测试、3 项 `install.ps1` 测试）、依赖审计。真实网络验证：对 176 MB 的发布包，在 20 MB 处人为切断第一次响应后，续传请求返回 206 并完成，最终 SHA-256 与发布的校验和一致；`install.sh` 在未指定版本的情况下完整安装成功。`install.ps1` 的解析和真实查询在 Windows CI 中分别于 Windows PowerShell 和 PowerShell 7 下执行。真实学校兼容范围以 `docs/VALIDATION.md` 为准。
