# lms-cli v0.4.5

## 修复与改进

- **更新检查更稳，也更少用到 API 额度。** github.com 页面请求遇到连接重置或异常状态码时，先重试一次，再退回 GitHub REST API。超时和校验失败（例如被重定向到非 GitHub 域名）不会重试，所以不会让等待时间翻倍，也不会重复发请求。更新仍需用户确认，不会静默安装；`LMS_UPDATE_CHECK=0` 仍可关闭自动检查。
- **`install.sh` 不再依赖匿名 API 解析最新版本。** 未指定版本时，脚本读取 github.com 最新版本页面的重定向，只接受本仓库的稳定版本标签；解析不出来时才退回原来的 API 方式。此前在共享出口 IP 上，匿名 API 的每小时额度用完会让首次安装失败。

## 说明

- 已知限制：`install.ps1` 没有改动，未指定版本时仍使用 REST API。PowerShell 脚本无法在本次发布环境中实测，因此保持原样；被限流时请使用 `-Version vX.Y.Z` 指定版本。
- 学校连接、授权流程和 MCP 工具与 0.4.4 相同；Codex 插件与 Claude Code 插件只同步了版本号。

## 安装与更新

推荐使用自包含 CLI 安装包；已经安装的用户可运行 `lms update`，确认后更新。程序更新保留学校配置、凭据和本地待办。独立授权 App 是可选附件，不是 CLI 使用的前置步骤。

请下载与操作系统和 CPU 架构匹配的附件，并使用同一 Release 的 `SHA256SUMS.txt` 核对文件完整性。学校额外要求的 CAPTCHA、推送 MFA 和设备合规检查仍需用户完成；本版本不绕过学校验证或保证永久免登录。

## 验证范围

发布前检查包括类型检查、118 项自动化测试（含 4 项重试策略测试和 3 项 `install.sh` 版本解析测试）、依赖审计；并用请求记录验证了 `install.sh` 在未指定版本时只访问 github.com 页面，以及网页失败时退回 API、两者都失败时给出明确错误且不安装。真实学校兼容范围以 `docs/VALIDATION.md` 为准。
